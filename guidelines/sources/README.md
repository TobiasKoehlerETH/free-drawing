## Verified catalogue corrections

- [ISO 128-3:2022](https://www.iso.org/standard/83356.html) replaces ISO 128-3:2020. [DIN Media lists the Swiss adoption SN EN ISO 128-3:2022-09](https://www.dinmedia.de/en/standard/sn-en-iso-128-3/360795412).
- [ISO 22081:2021](https://www.iso.org/standard/72514.html) supersedes ISO 2768-2:1989 and was confirmed in 2026. Its scope is general geometrical and size specifications for integral features; it is not a replacement tolerance table for class K.
- [ISO 21920-1:2021](https://www.iso.org/standard/72196.html) replaces ISO 1302:2002. A revision is in development; the catalogue still lists the 2021 publication.
- [ISO 8015:2011](https://www.iso.org/standard/55979.html) remains published, confirmed in 2021.
- [SNV's ISO GPS training](https://www.snv.ch/de/academy/iso-gps-schulung.html) explicitly addresses the relationship between ISO 2768-1, ISO 2768-2 and SN EN ISO 22081.

For normative release decisions, use the agreed editions through SNV-Connect or an existing company/library licence. The [Normen-Auszug 2026 catalogue](https://connect.snv.ch/de/normen-auszug-2026) identifies the full book. A publicly accessible preview does not establish access to all normative clauses.
